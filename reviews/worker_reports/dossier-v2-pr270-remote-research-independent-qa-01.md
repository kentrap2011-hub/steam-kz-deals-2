- **Проверено:** PR #270, точный HEAD `97f30cbfe3285610649c85e96d4ae179644d677e`, ветка `implement/dossier-v2-research-per-item-receipts-01`. Проверены правила `CHAT_PROTOCOL.md`, `CHAT_CONTEXT.md`, узкий маршрут и границы ответственности; код `scripts/dossier_notes_v2_per_item_receipts.py`, существующие вспомогательные проверки и все 14 тестовых сценариев `scripts/test_dossier_notes_v2_per_item_receipts.py`.
- **Подтверждено чтением кода:** отдельная передача записи одной игры и отдельная передача квитанции; проверка точной исходной игры и неизменённости сведений; один новый файл на коммит; проверка ожидаемого удалённого состояния перед записью, отправка без принудительной перезаписи, повторная загрузка удалённого коммита, проверка его предка и исходных байтов. При указанном настоящем GitHub и токене результат `github_receipt_confirmed=true` выставляется только после повторного аутентифицированного чтения адреса ветки и байтов файла через GitHub API (`_github_preflight`, `_single_remote_add`, `publish_receipt_remote`, строки 305–418 и 452–484).
- **Ошибки и независимость игр:** неверная игра, повторный файл, устаревшая версия ветки, конфликт при отправке и ошибка повторного чтения вызывают отказ, не успех. Отправка A не требуется для отправки B/C; написанный тест проверяет B после отказа A. Если файл-кандидат дошёл до удалённого хранилища, а квитанция не записалась или не подтвердилась, общий вызов завершается ошибкой и не объявляет успешное сохранение. Перед возможным продолжением необходимо выяснить фактическое состояние удалённой ветки; автоматической повторной отправки нет.
- **Разделение состояний:** подготовленные локально сведения, запись в отдельный тестовый Git, подтверждённая запись GitHub и окончательное принятие Dossier не смешиваются. Тестовый Git оставляет оба GitHub-подтверждения ложными. Окончательное принятие Dossier всегда остаётся ложным.

Прямых общих изменённых путей с PR #266 и PR #274 нет; прежний Dossier, производственные данные, GitHub Actions, расписания и правила включения V2 не изменены. PR #274 изменяет используемый PR #270 вспомогательный модуль `scripts/dossier_research_notes_v2.py`, поэтому совместимость версий после объединения разных PR здесь не проверена.
