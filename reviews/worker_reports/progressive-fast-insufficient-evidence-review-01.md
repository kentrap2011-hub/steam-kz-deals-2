## 6. Cross-game diagnosis

A common semantic-quality pattern is present.

Fast successfully produced a moderate/medium `analyzed_fit` for the immediately preceding BOKURA item using the same frozen profile and invocation, then returned four consecutive `insufficient_evidence` results for games where lightweight exact-product evidence was sufficient under the Fast contract.

The four cases span different evidence shapes:

- RV There Yet?: direct co-op/role-sharing mechanics strongly match the pinned social-play preference;
- Uncanny Tales: concrete walking-simulator/low-interaction structure strongly conflicts with the pinned active-core-loop preference;
- Nimbatus: campaign/tutorial/progression/mastery evidence resolves the main complexity risk enough for a provisional moderate fit;
- Borderlands 3: direct pinned personal franchise evidence plus exact-product continuity of the shooter-looter core supports provisional not-fit.

This makes “all four genuinely required Deep-level recovery” implausible under the actual Fast contract.

What is **not** proven is the mechanism. Repository evidence cannot distinguish among:

1. insufficient/light web retrieval and over-reliance on prepared short description/tags;
2. retrieval occurred, but the worker applied an excessively high/Deep-like confidence threshold;
3. a real transient retrieval/tool failure occurred but was not durably recorded.

Accordingly, the defect is confirmed at the semantic outcome layer, while runtime root cause remains open.
