# WORKER TASK — TOP SUMMARY FILTER BUTTONS 01

Task ID: `top-summary-filter-buttons-01`
Mode: `IMPLEMENT`
Report: `reviews/worker_reports/top-summary-filter-buttons-01.md`

## User request

На мобильном интерфейсе в верхнем блоке уже показаны четыре summary-карточки:
- `Новые`
- `Не смотрел`
- `Интересно`
- `Видел`

Пользователь хочет, чтобы все четыре верхние карточки стали кликабельными и работали как соответствующие фильтры/переходы по текущей ленте.

После того как верхняя карточка `Интересно` станет полноценной кликабельной точкой входа, отдельную нижнюю кнопку/вкладку `Интересно` нужно убрать как дублирующую. Верхняя `Интересно` остаётся единственной такой кнопкой в верхней навигационной области.

## Goal

Сделать верхние summary-карточки реальными интерактивными контролами без изменения существующей семантики состояний и без переработки остальной навигации.

Ожидаемое поведение:
1. Нажатие `Новые` открывает/включает существующее представление новых игр.
2. Нажатие `Не смотрел` открывает/включает существующее представление непросмотренных игр.
3. Нажатие `Интересно` открывает/включает существующее представление интересных игр.
4. Нажатие `Видел` открывает/включает существующее представление просмотренных игр.
5. Активное состояние должно быть визуально понятно и не конфликтовать с уже существующими фильтрами/вкладками.
6. Нижняя отдельная кнопка/вкладка `Интересно` удаляется как дубль только после того, как верхняя карточка полностью заменяет её функцию.
7. Счётчики на карточках продолжают отображать текущие реальные значения.

## Read first

Не делать широкий поиск по истории Git/Actions.

## Critical boundaries

Do NOT:
- менять semantic/Taste/ranking правила;
- менять значения или расчёт счётчиков без отдельного доказанного дефекта;
- менять giveaway/ITAD/IGDB логику;
- менять mobile cache/data ownership;
- перерабатывать общий дизайн страницы;
- создавать второй набор параллельных filter state;
- менять смысл `Новые`, `Не смотрел`, `Интересно`, `Видел`.

Использовать существующее состояние/фильтрацию как единственный источник истины.
