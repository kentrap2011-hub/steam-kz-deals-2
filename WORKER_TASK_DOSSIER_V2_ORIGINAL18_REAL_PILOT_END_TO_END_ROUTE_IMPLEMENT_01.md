## Цель и завершённый результат
Дать работающий **исполняемый** и воспроизводимый one-shot маршрут:
approved original 18 → immutable GitHub scope/manifest/marker → ограниченное разрешение → Research на каждую из 18 игр → отдельный Assembly на каждую игру (с независимым поиском источников) → GitHub receipt / строгая проверка → штатное изолированное сохранение готовых результатов с отчётами по всем 18. Каждый настоящий успешный шаг должен иметь GitHub run/ref/receipt. Нормальная ошибочная/неполная игра не должна блокировать остальные.

Задача НЕ закрывается одним описанием архитектуры или зелёными синтетическими тестами. Нужен исполняемый маршрут в коде и, если есть поддерживаемый доступ, фактический пилот; если запуск недоступен в данном чате, выдать конкретную короткую последовательность существующих кнопок / команд и точные одноразовые launcher prompts, а не объявлять запуск выполненным.

Не создавать альтернативный publisher/receipt writer, вторую очередь, новый scheduler, webhook или повторные тестовые аудиты. Повторно не исследовать уже доказанные 14/14 тестов.
- Текущее состояние `config/dossier_research_notes_v2_contract.json` содержит `active=false`, `authorized_for_semantic_execution=false`, `manual_v2_issuer.enabled=false`, пустой `human_grant`. Семантическую работу выполняет **явно запущенный отдельный ChatGPT one-shot worker** по каноническим prompt(ам) и только по точной GitHub-подготовленной очереди; GitHub Actions сам не умеет проводить полноценный LLM Research/Assembly.
