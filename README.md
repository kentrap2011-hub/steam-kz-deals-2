# steam-kz-deals-2

Для любой новой рабочей сессии сначала прочитать `CHAT_CONTEXT.md`.

`CHAT_CONTEXT.md` — компактная карта проекта: источники истины, минимальный набор файлов для разных типов задач и правила контекстной гигиены.

`PROJECT_RULES.md` содержит подтверждённые пользователем цели и долгосрочные договорённости, но не должен автоматически читаться целиком для каждой задачи. Открывать его только когда меняются или проверяются правила отбора, приоритеты, формат рассылки либо архитектурные договорённости.

Если новая договорённость пользователя меняет поведение рассылки или взаимодействие с ним, сохранить долговечный результат в соответствующем каноническом файле GitHub, а не полагаться на историю чата.
